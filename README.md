# 🛒 Flipkart Sales Analysis Using PySpark  Databricks

## 📌 Project Overview

This project focuses on analyzing Flipkart sales data using **PySpark and Databricks**. The project involves data loading, data exploration, data cleaning, data transformation, business analysis, and visualization to understand sales performance and identify useful business insights.

## 🎯 Objectives

- Load and explore the Flipkart sales dataset.
- Check and handle missing values.
- Identify and remove duplicate records.
- Perform data cleaning and transformation.
- Analyze sales by product category and city.
- Identify top-selling products.
- Create visualizations to understand sales performance.
- Generate insights to support business decision-making.

## 🛠️ Tools and Technologies

- **Platform:** Databricks
- **Programming Language:** Python
- **Data Processing:** PySpark
- **Dataset Format:** CSV
- **Visualization:** Databricks Visualizations
- **Version Control:** GitHub

## 📂 Dataset Information

- **Dataset Name:** Flipkart Sales Dataset
- **Number of Rows:** 200
- **Number of Columns:** 10

### Dataset Columns

| Column Name | Description |
|---|---|
| Order_ID | Unique order identifier |
| Customer_ID | Customer identifier |
| Product_Category | Product category |
| Product_Name | Product name |
| Order_Date | Date of order |
| Quantity | Units purchased |
| Unit_Price | Price per unit |
| Discount_Percent | Discount percentage |
| City | Customer/order city |
| Payment_Method | Payment type |

## 🔄 Project Workflow

1. **Data Ingestion:** Load the CSV dataset into Databricks.
2. **Data Exploration:** Check rows, columns, schema, and descriptive statistics.
3. **Data Cleaning:** Handle missing values, duplicates, and data types.
4. **Data Transformation:** Create calculated columns and prepare data for analysis.
5. **Business Analysis:** Analyze sales by category, product, and city.
6. **Data Visualization:** Create charts to present sales performance and insights.

## 📓 Databricks Notebook Structure

The project is organized into five notebooks:

1. `01_Data_Ingestion`
2. `02_Data_Cleaning`
3. `03_Data_Transformation`
4. `04_Business_Analysis`
5. `05_Visualization_Dashboard`

## 📊 Business Analysis

The following analyses are performed:

- Category-wise Sales Analysis
- Product-wise Sales Analysis
- City-wise Sales Analysis
- Average Rating Analysis, if rating data is available
- Top 5 Sales Records
- Total Sales and Quantity Analysis
